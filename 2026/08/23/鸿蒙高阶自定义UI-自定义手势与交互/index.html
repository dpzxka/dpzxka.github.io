八、常见问题

Q1：父子组件都绑定了TapGesture，谁先响应？

默认子组件优先。如果需要父组件优先，使用 .priorityGesture() 绑定。LongPressGesture有特殊行为：设置的触发最短时间小于其他组件的会优先响应。

Q2：如何实现长按后拖拽？

使用 GestureGroup(GestureMode.Sequence, LongPressGesture(), PanGesture())。顺序识别模式下，必须先触发长按，之后的拖拽才能被识别。

Q3：手势和滚动容器冲突怎么办？

使用 .parallelGesture() 让手势与系统滚动手势并行识别，或者使用 .onGestureRecognizerJudgeBegin 在特定条件下拦截手势判定。

Q4：GestureEvent 的 offsetX 和 offsetX有何区别？

offsetX/offsetY 是相对于手势起点的累计偏移量；localX/localY 是相对于组件的坐标。拖拽时一般用 offsetX/Y。

Q5：如何实现双指缩放+旋转同时生效？

使用 GestureGroup(GestureMode.Parallel, PinchGesture(), RotationGesture())。并行模式下两个手势可以同时识别，各自维护独立的状态变量。
