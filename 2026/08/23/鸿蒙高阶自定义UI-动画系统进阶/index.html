一、ArkUI 动画体系全景

ArkUI的动画分为两大类：

类型 触发方式 适用场景 API版本
隐式动画 属性值变化自动触发 简单属性过渡 API 7+
显式动画 animateTo() 手动触发 复杂协调动画 API 7+

在此基础上，还有：

  • 转场动画：组件插入/删除时的过渡效果
  • 关键帧动画：分段动画，指定关键时刻的状态
  • 属性动画：组件属性的链式动画声明
  • 弹簧动画：基于物理模型的弹性动画

八、性能优化

8.1 可动画属性 vs 不可动画属性

属性类型 性能影响 示例
仿射属性（推荐） 低，不触发布局计算 translate/rotate/scale/opacity

优化原则：优先使用仿射属性实现动画效果。如果必须改变布局属性，配合 renderFit 使用。

8.2 弹簧动画的优势

弹簧动画相比传统贝塞尔曲线：

  • 基于物理模型，更自然
  • 自动继承前一个动画的状态和速度
  • 动画时长自动计算，无需硬编码
  • 支持跟手交互（responsiveSpringMotion）

十、常见问题

Q1：animation 属性和 animateTo 有什么区别？

animation() 是隐式动画，对组件前面的可动画属性生效，属性变化时自动触发；animateTo() 是显式动画，在闭包内通过状态变量改变UI，可同时控制多个组件的动画。简单属性过渡用animation，复杂协调动画用animateTo。

Q2：弹簧动画的duration参数为什么不生效？

弹簧动画（springMotion/responsiveSpringMotion）的时长由曲线参数和属性变化量自动计算，开发者指定的duration不生效。这是设计如此——弹簧动画追求物理真实性，时长应该由弹簧参数决定。

Q3：关键帧动画为什么不能用spring曲线？

因为spring曲线的时长是自动计算的，而关键帧动画需要精确控制每个时刻的时间点（time参数）。两者的设计理念冲突，所以关键帧动画不支持spring相关曲线。

Q4：TransitionEffect的combine和asymmetric有什么区别？

combine 是叠加多个转场效果（如同时淡入+缩放+旋转），用于同一个阶段（进入或退出）；asymmetric 是让进入和退出使用不同的效果组合，实现非对称转场。
