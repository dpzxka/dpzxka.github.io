前言

今天，我们将学习两个”小而精”的能力——深度估计和设备位姿。它们不像平面检测或体素重建那样是独立的”功能模块”，而是 AR 引擎的底层基础设施，贯穿于所有 AR 体验之中：

  • 深度估计告诉你目标物体离设备有多远
  • 设备位姿告诉你设备自身在空间中的位置和朝向

理解了这两者，你就真正掌握了 AR Engine 的”空间坐标系”——不再只是被动使用封装好的 API，而是能精确理解每一帧中”设备在哪儿””物体在哪儿””距离有多远”。

第一部分：深度估计

一、什么是深度估计？

深度估计（Depth Estimation）是 AR Engine 通过深度传感器（ToF 或双目视觉）计算物体表面到相机的距离的能力。输出形式有两种：

数据类型 说明 API
深度图像 16-bit 灰度图，每个像素值表示该点距离（毫米） acquireDepthImage16Bits()
置信度图像 8-bit 灰度图，每个像素值表示深度可信度 acquireDepthConfidenceImage()

应用场景

  • AR 遮挡：虚拟物体可以真实地被现实物体遮挡（需要深度图像 + 自定义渲染）
  • 距离测量：测量物体到相机的距离（单点测距）
  • 空间感知：理解场景的 3D 结构
  • 碰撞检测：虚拟物体与真实环境产生物理交互

二、配置深度估计

深度估计通过 depthMode 配置启用：

配置兼容性：

同时启用 兼容性
depthMode: AUTOMATIC + meshMode: ENABLE ✅ 兼容
depthMode: AUTOMATIC + semanticDenseMode: CUBE_VOLUME ❌ 冲突
depthMode: AUTOMATIC + planeFindingMode: HORIZONTAL_AND_VERTICAL ✅ 兼容

深度估计与场景网格兼容，但与 CUBE_VOLUME 互斥，因为都需要独占深度计算资源。

五、深度估计 FAQ

Q1: 所有设备都支持深度估计吗？

不是。深度估计需要设备具备 ToF（Time-of-Flight）深度传感器或双目视觉能力。部分中低端设备可能不支持。建议在实际部署前做能力检测。

Q2: 深度图的分辨率和帧率是多少？

取决于设备硬件。典型值：

  • ToF 设备：640×480 @ 30fps
  • 双目视觉设备：分辨率可能更低

可以通过 depthImage.width 和 depthImage.height 在运行时获取实际分辨率。

Q3: 深度值的范围是多少？

典型有效范围是 0.2m ~ 8.0m。超出此范围的值不可靠。深度值 0 表示无效像素（未获取到深度信息）。

Q4: 为什么我的中心点深度总是 0？

可能原因：

  1. 设备不支持：运行在不支持深度估计的设备上
  2. 配置错误：depthMode 未设为 AUTOMATIC
  3. 启动初期：启动后前几帧可能还没有深度数据
  4. 中心点无物体：中心点对准的是天空/墙面空洞
  5. 字节序错误：getUint16 的 littleEndian 参数与设备实际字节序不匹配

第二部分：设备位姿

六、什么是设备位姿？

设备位姿（Device Pose）是 AR 引擎最核心的基础能力——它回答了一个基本问题：“手机现在在空间的什么位置、朝向哪个方向？”

AR Engine 通过融合以下数据来计算 6-DoF（六自由度）位姿：

    flowchart LR
    subgraph 传感器输入
        I1[摄像头图像] --> F[视觉惯性<br>里程计 VIO]
        I2[陀螺仪] --> F
        I3[加速度计] --> F
    end
    subgraph 位姿输出
        F --> P1[位置 x, y, z<br>3 自由度平移]
        F --> P2[旋转 rx, ry, rz<br>3 自由度旋转]
    end
    subgraph 状态判断
        F --> S[跟踪状态<br>stateReason]
    end

    style P2 fill:#e94560,color:#fff

八、位姿的应用场景

8.1 坐标系理解

AR Engine 采用右手坐标系：

  • Y 轴向上（与重力方向相反）
  • X 轴向右（相对于初始朝向）
  • Z 轴指向相机（初始面向方向）

初始位置（0, 0, 0）是相机启动时的位置。

8.2 位姿数据的典型应用

应用 原理
路径记录 持续记录 pose.translation，构建设备移动轨迹
虚拟内容固定 将虚拟物体放在某个位姿，之后每帧用当前 pose 做差
空间锚点 记录某时刻的位姿，之后回到同一位置时触发事件
手势/动作识别 分析位姿变化模式（如”画圈”、”前推”）
多设备对齐 通过共享位姿数据实现多设备 AR 同步
