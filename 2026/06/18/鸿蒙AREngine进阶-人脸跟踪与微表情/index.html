前言

这是 AREngine 进阶系列的第六篇，也是最后一篇专题文章。在此之前，我们依次学习了：

  • 完全指南：会话管理、平面检测、模型渲染
  • 点云·场景网格：特征点、三角网格重建与着色
  • 图像跟踪：图片识别、虚拟内容叠加
  • 高精几何重建：体素重建、体积测量
  • 深度估计与设备位姿：测距与空间定位
  • 人体骨骼点识别与跟踪：20 关键点姿态分析

今天的学习内容可能是这六篇文章中最有趣的一个——人脸跟踪与微表情（Face Tracking）。

想象这样的场景：

  • 你对着屏幕微笑，AR 虚拟角色也做出相同的微笑表情
  • 你抬头扬眉，AR 信息面板随之展开
  • 你噘嘴吹气，屏幕上的生日蛋糕蜡烛随之熄灭
  • 你戴上虚拟帽子，帽子始终贴合你的头部运动

这些体验的核心技术就是人脸跟踪——让 AR 引擎实时捕捉面部的几何形状、位置朝向和细微表情变化。

在本章中，你将学到：

  • 人脸跟踪的技术原理与数据维度
  • ARType.FACE 的会话配置与 ARTrackableType.FACE 数据获取
  • ARFace 的面部网格几何体系（4000+ 顶点、7000+ 三角面）
  • 64 种 Blend Shape 表情系数的含义与用法
  • ARAnimojiTriangleLabel 面部区域分类
  • 基于 Canvas 的面部网格/表情可视化
  • 基于 Blend Shape 的实时表情识别

前置条件：人脸跟踪需要 API 23+（HarmonyOS 6.1.0+），且必须使用前置摄像头（FRONT camera）。请确认你的设备已满足要求。

一、人脸跟踪能力全景

1.1 什么是人脸跟踪？

人脸跟踪是 AR Engine 提供的面部感知与表情分析能力。它通过分析前置相机画面中的人脸图像，实时构建出精细的面部 3D 网格，并同步计算出 64 种面部表情系数（Blend Shapes）。

与传统的”人脸检测”（仅在画面中框出人脸位置）不同，人脸跟踪能够：

  • 精确跟踪面部的位置和朝向（6-DoF）
  • 重建面部的几何形状（顶点级精度）
  • 解析微表情变化（眉毛、眼睛、嘴巴、脸颊等 64 个维度）

1.2 数据维度总览

三、创建人脸跟踪会话

3.1 会话配置

Face Tracking 的配置与 Body Tracking 类似，但有两个关键区别：

  1. type 必须设置为 arEngine.ARType.FACE
  2. cameraLensFacing 仅支持 FRONT
  3. multiFaceMode 可选单人或多人模式

3.2 会话创建

Face Tracking 的会话创建流程与 Body Tracking 几乎一致，但获取数据的方式有所不同——Face 数据通过 session.getAllTrackables() 获取，而不是 frame.acquireBodySkeleton()。

关键区别：与 Body Tracking 不同，Face Tracking 的 ARFace 对象是通过 session.getAllTrackables(ARTrackableType.FACE) 获取的，而不是 frame 上的直接方法。因此需要先保存 ARViewContext.session 引用。

四、获取面部数据

4.1 ARFace 核心 API

ARFace 对象代表一个被跟踪的人脸实例，包含以下数据方法：

方法 返回值 说明
getGeometry() ARFaceGeometry 面部网格数据（顶点、索引、纹理坐标）
getBlendShapes() ARBlendShapes 64 维表情系数
getPose() ARPose 头部 6-DoF 位姿
getTrackableId() number 唯一标识

4.2 面部网格几何

ARFaceGeometry 是面部网格的几何数据容器，包含构成面部 3D 网格的所有原始数据：

理解面部网格数据

面部网格是一个静止拓扑、动态位置的网格系统：

  • 拓扑固定：顶点数量和连接关系在初始化后不会改变（始终 4000 个顶点、7000 个三角形）
  • 位置动态：每个顶点的 3D 坐标会随面部表情和头部运动而实时更新
  • 世界坐标：顶点坐标在 AR 世界坐标系中，以设备为原点

4.3 表情系数（Blend Shapes）

Blend Shapes 是人脸跟踪的核心数据——64 个 0.0~1.0 的浮点数，每个数代表一种面部肌肉运动的强度。0.0 为中立，1.0 为最大幅度。

八、性能与最佳实践

8.1 相机方向限制

人脸跟踪仅支持前置摄像头（FRONT）。如果配置为 REAR，init() 会失败。

8.2 多人脸性能

多人脸模式下：

  • 每增加一张脸，CPU 负载显著增加
  • Blend Shapes 和网格都会独立计算
  • 大多数场景使用单脸模式即可

8.3 网格绘制的性能策略

面部网格包含 4000 个顶点、7000 个三角形。在 Canvas 上实时绘制线框需要优化：

  • 降低绘制频率：不需要每帧都重绘网格（如改用 1/4 帧率绘制）
  • 减少三角面数：可以从索引数组中每隔一个三角形采样
  • 使用 AGP：对于生产级面部效果，使用 ArkGraphics 3D 进行 GPU 渲染
  • 避免逐顶点操作：在帧回调中不要遍历所有顶点做复杂运算

8.4 Blend Shapes 的使用建议

  • 阈值过滤：忽略小于 0.1 的值，减少无效计算
  • 帧级平滑：对 Blend Shape 值做指数移动平均，防止抖动

8.5 光照要求

  • 面部需要均匀照明，避免半张脸在阴影中
  • 在暗光环境下，人脸跟踪可能无法启动或精度显著下降
  • 避免强逆光（面部过暗会导致关键点丢失）
